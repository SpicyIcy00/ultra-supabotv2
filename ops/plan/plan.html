What changed in how we work

Several rules were written when every test ran on Opus and a full run cost $4.79. On DeepSeek the same run is about fifty cents, so the rules that only existed to save money are gone. The ones that keep the numbers honest stay.

Live tests every card, every waveEach agent tests its own card on real answers before it hands back. After each wave the lead runs the whole suite. Before, nothing live ran until the end of a phase.
The tests read the right priceThe test tools still used Anthropic’s key and Opus’s prices, so on DeepSeek they would have skipped, or reported about twenty times the real cost. Fixed.
Five runs, and re-run anything in doubtThe same question takes 90 to 325 seconds, so each speed check runs five times, not three. A doubtful number gets measured again instead of trusted.
Pushed live when greenPasting a wave’s prompt is your yes for that wave, so finished work goes live instead of piling up. A failing test is never pushed.
The screen can change againThe freeze from 18 September is lifted. Bob on every page and the designed page types need it.
Old tests don’t hold new decisions backA test that enforces something we reversed today — forcing a page on every answer, for example — gets rewritten, and the agent names it.

Wave 1 — the base · done 22 Sep

Merged, measured and pushed. What is left to spend on the open cards’ own tests: $0.75 — each card tests itself on live answers, about four turns at four cents each. The full check after each wave is about $1.90 more, so about $4.55 is left in all.

How it runs. Each agent works in its own copy of the code, so none can collide. The lead session merges them one at a time, runs every test after each, then runs the whole live test suite, the full capability test, and a speed check of three kinds of question, five times each. When every test passes, it pushes the update live. Done when a fact comes back in about ten seconds, a narrow question in well under a minute, and every action phrase that failed the test passes in the same words.
