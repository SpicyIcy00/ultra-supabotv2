F1

One read that already has the picture

no eval

Every broad question makes the same twenty or thirty reads and then thinks for minutes over the raw results. One read does all of it in code and hands Bob the findings already written as short plain sentences — the numbers put in by code, never by him — each with its receipt. It is built from exactly what his best broad answers already read, not guessed at, and he can still dig further when something needs explaining.

Done when: a fresh broad question is one read and two rounds, measured over several answers, and the page is judged against today’s.

The morning, answered before you ask

needs your time and your yesno eval

At the time you choose, Bob answers “how are we doing” on his own, so the page is waiting when you open the app. Asked again the same day, it is reused until the data changes, and says when it was read. It starts switched off — you switch it on. The shop lines also stop showing internal names, and “usual” is defined as the same weekday over several weeks rather than one.

Done when: the room opens on the morning’s page with no question typed, and a same-day repeat costs no model turn.

F3

He writes the findings, code lays them out

no eval

Bob writes sections — a heading that states the finding, a few paragraphs, and the figures it rests on — and code picks each chart’s type, size and position, the way it already does when he leaves them out. Every word stays his. The layout is written once instead of twice, a figure can no longer be left off the page, and it is the shape that lets the page appear while it is being written.

Done when: a broad page is written as sections and looks as good as today’s, measured for time over several answers.

F4

What the other cards leave

no eval

The smaller fixes the research found, done only where the first three have not already made them moot: DeepSeek gets its thinking setting in the one place it reads it (it has been thinking at full strength on every question); a round ends once the page carries the answer, instead of forcing another; the instructions that ask for things no page draws are deleted; a bug that throws away every highlight he is asked to mark is fixed; and the cause of his answers opening with “You’re right —” to the system’s own correction is found before anything is called a fix.

Done when: each is measured before and after, and the ones that bought nothing are said to.

F5

The page appears while it is written

no eval

Instead of a blank screen until the very end, each section appears as Bob finishes it, marked as still arriving until the checks pass. It only hides the last part of the wait — most of the time is thinking before any of the page is written — and whether DeepSeek can stream it at all is untested, so that is measured first.

Done when: the first section is on screen before the answer finishes, on the model Bob runs on.

One decision that is yours

The costliest correction is “you didn’t mention this warning — rewrite your whole answer.” Code could put the warning beside the right figure itself and save that round. But having Bob say it in his own words is a trade you chose, so it stays as it is until you say otherwise.
