5 · Three ways it gets cheaper

Measured: 72% of a run is round trips, not questions. Cache writes and reads scale with how many times George thinks, and the four gate questions are only 63c of a $1.51 run. So cutting questions barely helps.

Replay instead of re-running. Every trust check is a function of the answer and the rows, so a card that changes only a check needs no live turn at all. That is built and proved: tests/evals/corpus.py, replayed against your last run, found the leaked column name on its own for nothing.

The effort card was supposed to be the real discount and was not. Built on 14 September, it cut round trips by a third and the answer by eight seconds — and the same eleven questions still cost $1.62. Fewer, deeper turns is not fewer tokens: he writes less and thinks more in one go. So $1.51 stays the price of a run, and the saving that card bought is your waiting time, not money.

Keep a pair of runs inside an hour, so the second reads the cached prompt instead of paying to write it again.

What could go wrong, and what the plan does about it

A card's number doesn't moveIt says so in the close-out and names the cause. P1.b did exactly this. The next card is not started until the cause is written down; the answer is never "try harder".
A session wants to rebuildThe protocol says stop and ask; the default is no. If it happens twice on one card, that card is wrong and a Fable review session rewrites it.
Two sessions in one treeIt has happened. Every card commits before it ends; a session checks git log against its start; a swept commit is named in the close-out, not rewritten.
Runs flapStyle checks flap and trust rows do not — leading with a reading was every non-trust failure across four runs of the old suite. The new one reports style as a rate and only asserts it behind a flag, which a card should not set.
A deploy takes production downP0.4 made the deploy migrate itself and /health tell the truth. A card with a migration is pushed in the morning, watched five minutes, and the close-out says so.
You stop dogfoodingThen the plan is measuring itself. Five minutes a morning is the whole cost; the log's Open list is the only thing that reorders the cards.

The foolproof part is not the cards. It is that every session starts by reading one file, does one thing, and ends with a number, and that you only ever say what's wrong. Everything else is written down where the next session will find it.
